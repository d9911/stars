# Star Rating

Доступный браузерный интерфейс для выбора и отображения оценки от одной до пяти звёзд.

## Веб-адрес

[stars.d9911.org](https://stars.d9911.org/)

## Возможности

- Выбирает оценку от одной до пяти с помощью кнопок-звёзд или элемента выбора.
- Обновляет активные звёзды, текстовый результат в динамически обновляемой области и доступное состояние кнопок.
- Предварительно показывает оценку при наведении указателя и скачивает текущую оценку в SVG-файл.
- Поддерживает светлую и тёмную темы, а также английский, испанский и русский интерфейс.

## Использование

1. Выберите оценку кнопками-звёздами или выпадающим списком.
2. Проверьте обновлённый текстовый результат и звёзды.
3. Нажмите **Скачать SVG**, чтобы сохранить текущую оценку как графику.

## Локальный запуск

Это статический сайт. В корне репозитория запустите любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).
